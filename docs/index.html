RAG 是什么？它为什么能降低没有证据支持的回答风险？
Grounded answer
RAG 会在生成回答之前先从外部知识库检索相关信息，并把这些证据作为上下文提供给大语言模型 [S1][S2]。这样回答不只依赖模型参数中的记忆，因此可以降低没有证据支持的回答风险；不过，如果检索到的内容本身错误或无关，RAG 仍然可能产生不可靠答案 [S2]。
